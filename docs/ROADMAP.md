# Roadmap

## Phase 0 — Product & Architecture

Define product boundaries, domain model, architecture, security, integration strategy, observability, experimentation, and engineering workflow.

**Status:** In progress.

## Phase 1 — Opportunity Intelligence

Collect and normalize opportunities, evaluate configurable criteria, persist analysis, and expose results through an API/dashboard.

**Status:** Not started.

## Phase 2 — Proposal System

Proposal preparation, pricing, estimation, approval policy, and submission through platform adapters.

## Phase 3 — Project Execution

Project planning, task execution, capability dispatch, verification, delivery preparation, and execution monitoring.

## Phase 4 — Client Communication

Communication state machine, requirement clarification, negotiation support, delivery communication, and auditability.

## Phase 5 — Revision Management

Feedback interpretation, change requests, impact analysis, revision planning, execution, validation, and redelivery.

## Phase 6 — Intelligence & Business Analytics

Success rates, revenue, costs, margins, delivery time, client outcomes, capability performance, and improvement recommendations.

## Phase 7 — Experimental Platform

Run experimental versions alongside stable versions, measure hypotheses, and promote or reject versions based on defined metrics.

## Phase 8 — Windows & Mobile Interfaces

Provide dedicated client interfaces over the backend API without duplicating business logic.
